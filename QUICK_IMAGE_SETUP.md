## 🎯 Quick Setup (3 Steps)

Visit these sites and search for relevant images:

**For Overview Section (`overview-bg.jpg`)**

- Recommended: https://unsplash.com/s/photos/education

**For Law Explorer (`law-bg.jpg`)**

- Recommended: https://unsplash.com/s/photos/law-books

**For Reality vs Law (`reality-bg.jpg`)**

- Recommended: https://unsplash.com/s/photos/community

**For Case Deck (`cases-bg.jpg`)**
- Search: "court" "justice" "scales"
- Recommended: https://unsplash.com/s/photos/justice-scales

### Step 2: Download & Rename

1. Download your chosen images
2. Rename them exactly as shown above:
   - `overview-bg.jpg`
   - `law-bg.jpg`
   - `reality-bg.jpg`
   - `cases-bg.jpg`

### Step 3: Place in Public Folder

Move all images to: `gensoc/public/`

That's it! The website will automatically use them.

## 🎨 What If I Don't Add Images?

**No problem!** The website already looks great with gradient backgrounds. Images are just an optional enhancement. If you don't add them, you'll simply see the beautiful gradients that are already there.

## 📊 Image Best Practices

- **Size:** 1920x1080 or larger (for high-res displays)
- **Format:** JPG (smaller file size) or PNG (higher quality)
- **Compression:** Use https://tinypng.com to reduce file size
- **Target:** Keep each image under 500KB

## 🔄 Testing

After adding images:
```bash
cd gensoc
npm run dev
```

Visit http://localhost:3000 and scroll through the sections to see your images!

## 💡 Pro Tips

1. **Subtle is better** - Images are already set to low opacity, but choose images that won't distract from text
2. **Relevant themes** - Match the image to the section content
3. **High quality** - Download the highest resolution available
4. **Consistent style** - Try to keep similar color tones across all images
