## 🔍 Best Free Image Resources

1. **Unsplash** - https://unsplash.com
   - High quality, free to use
   - Search: "philippines", "law", "justice", "women empowerment"

2. **Pexels** - https://www.pexels.com
   - Free stock photos
   - Good for professional/legal themes

3. **Pixabay** - https://pixabay.com
   - Large variety, completely free
   - Search similar terms

4. **Wikimedia Commons** - https://commons.wikimedia.org
   - Philippine-specific images
   - Government buildings, official photos

## 📐 Image Specifications

- **Format:** JPG or PNG
- **Size:** 1920x1080 or larger (for backgrounds)
- **File size:** Try to keep under 500KB for web performance
- **Optimization:** Use tools like TinyPNG or Squoosh to compress

## 🎨 Style Guidelines

- **Opacity:** Images will have overlays (60-80% opacity)
- **Color tone:** Warm tones work well with the purple/rose theme
- **Contrast:** Ensure text remains readable over images
- **Professional:** Keep images appropriate for educational content

## 🚀 How to Add Images

1. Download your chosen images
2. Rename them according to the filenames above
3. Place them in `gensoc/public/` folder
4. The code will automatically use them!

## 💡 Alternative: Use Gradient Backgrounds

If you prefer not to use images, the code already includes beautiful gradient backgrounds as fallbacks. The images are optional enhancements!
